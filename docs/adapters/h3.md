# h3 Adapter

Use the h3 adapter when Zelavis should be mounted into an h3 application.

## Basic usage

```ts
import { H3, serve } from "h3";
import { Zelavis } from "zelavis";
import { zelavisH3, zelavisNode } from "zelavis/adapters";

const app = new H3();
const zelavis = new Zelavis({
  adapter: zelavisH3({ platform: zelavisNode() }),
});

app.use("/**", zelavis.adapter.h3Handler());

serve(app, { port: 3000 });
```

## Options

```ts
zelavisH3({
  platform?: ZelavisAdapterPlatform;
})
```

## Good fit

- h3-based apps and tooling
- Smaller Web-style servers that still want mounted middleware
- Setups where Zelavis should sit inside a broader h3 app

## Notes

- The h3 app still owns server startup and any surrounding middleware.
- Zelavis continues to mount its dashboard and APIs using the runtime's `rootPath`, prefix, and version settings.
- h3 mounting is useful when you want Zelavis beside custom h3 routes instead of as a standalone server.
