# Collections Management

Compare two integration patterns: **JSON API** (client-side) vs **TypeScript API** (server-side).

<CollectionsDemo />

## How It Works

### TypeScript API

Uses TanStack Start server functions to call Zelavis methods directly:

```typescript
const createCollection = createServerFn({ method: "POST" }).handler(
  async ({ data }) => {
    await db.createCollection((s) => ({
      collectionName: data.collectionName,
      schema: { name: s.string() },
    }));
  }
);
```

### JSON API

Uses fetch to call Zelavis's HTTP API:

```typescript
const response = await fetch("/api/zelavis/json/create-collection", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ collectionName: "users" }),
});
```
