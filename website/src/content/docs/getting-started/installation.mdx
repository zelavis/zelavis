<TabItem label="Create new project">

Use the `create zelavis` command to scaffold a new project with everything configured:

```bash
pnpm create zelavis@latest
```

```bash
npm create zelavis@latest
```

```bash
bunx create-zelavis@latest
```

The setup wizard will ask for your project name, preferred framework, and deployment target.

</TabItem>
<TabItem label="Add to existing framework">

Use `zelavis bootstrap` to add Zelavis endpoints to an existing app.

The command is interactive by default. Use `--yes` with explicit flags for non-interactive setup:

```bash
pnpm dlx @zelavis/cli bootstrap --help
```

#### React Router

```bash
pnpm dlx @zelavis/cli bootstrap react-router
```

Generates:

```txt
app/lib/zelavis.server.ts
app/routes/zelavis.$.ts
```

#### Next.js App Router

```bash
pnpm dlx @zelavis/cli bootstrap nextjs --router app
```

Generates:

```txt
lib/zelavis.server.ts
app/zelavis/[[...path]]/route.ts
```

#### Next.js Pages Router

```bash
pnpm dlx @zelavis/cli bootstrap nextjs --router pages
```

Generates:

```txt
lib/zelavis.ts
pages/api/zelavis/[[...path]].ts
next.config.ts
```

#### Adapter selection

Each bootstrap command asks which environment the app will run on. Pass `--adapter` to skip the prompt:

```bash
pnpm dlx @zelavis/cli bootstrap react-router --adapter node --yes
pnpm dlx @zelavis/cli bootstrap nextjs --router app --adapter vercel --yes
```

Supported adapters: `node`, `bun`, `cloudflare`, `vercel`, `netlify`.

See the [CLI docs](/cli) for the full command reference.
