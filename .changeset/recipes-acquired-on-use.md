Creating a Project from an app or upgrading one now installs the app's newest listed version first, on the server, when it is not installed yet. This works the same from the dashboard, the API, the SDK and the CLI. A WordPress site created while WordPress came with the Platform now upgrades with one click: before, the Upgrade button failed with "listed in the Marketplace but not installed yet". App cards in the Marketplace no longer offer **Update**, because each Project keeps its own version and moves only when you upgrade it. Plugins and frontends keep their **Update** button.
